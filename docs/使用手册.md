## 1. 认识桌面端与 Web 端

R18 媒体库由 Windows 桌面程序与内置 Web 服务组成。桌面程序负责数据库、磁盘文件、下载、扫描与本地播放；浏览器通过它提供的服务管理同一批数据。关闭桌面进程后，网页服务、下载和后台监控也会停止。

![媒体库首页](assets/manual/home.png)

| 左侧入口 | 用途 |
| --- | --- |
| 媒体库 | 按库、社团和作品浏览本地文件 |
| 下载管理 | 下载任务、失败重试、已下载记录 |
| 作品搜索 | 外部来源检索和加入下载 |
| 作家监控 | 定时检查 FANBOX 归档作家，并为新投稿创建任务 |
| 作品标签／作品社团／作品形式 | 从不同维度浏览已入库作品 |
| 我的收藏 | 浏览手动收藏的作品 |
| 账号访问 | FANBOX、pixiv、E-Hentai 登录状态与凭据配置 |
| 系统设置 | 下载、代理、媒体库、图床等配置 |

各页面右上角（或工具栏末尾）的 **?** 按钮会打开本手册中与当前页面对应的章节；系统设置的每个分区标题旁也有自己的 **?**。

**网页路径指向运行桌面程序的电脑。** 手机网页中填写 `D:\Media`，表示服务端电脑的 D 盘，不表示手机或当前浏览设备的磁盘；下载也保存到服务端。

| 能力 | 桌面端 | Web 端 |
| --- | --- | --- |
| 浏览、分类、收藏、下载队列、作家监控 | 支持 | 支持 |
| 添加媒体库目录 | 系统目录选择框 | 填服务端绝对路径 |
| 音视频播放 | LibVLC 视频、NAudio 音频 | 浏览器播放器，格式支持由浏览器决定 |
| asmr.one 账号与 SOU 优先源 | 可配置并使用直链入口 | 当前没有专用直链入口，可查看共用队列 |
| E-Hentai 站点、画质；pixiv 分级、匹配、画质 | 可设置 | 使用服务端配置 |
| 外部访问与门户 SSO 参数 | 可设置 | 外部访问状态只读 |
| 游戏 | 本机运行 | 可请求服务端运行或远程串流 |
| 图片翻译 | 已有设置及依赖管理，见第 17 节 | 当前没有翻译操作入口 |

## 2. 安装、启动与首次配置

### 2.1 从源码运行

需要 Windows 和 .NET 10 SDK。在仓库根目录打开终端：

```powershell
dotnet build src/R-18MediaLibrary.csproj
dotnet run --project src/R-18MediaLibrary.csproj
```

也可双击根目录 `start.bat`，它会切换到项目目录并以 Release 配置运行。首次构建会还原依赖。

### 2.2 使用发布版

运行根目录 `publish.bat` 生成 `publish/R-18MediaLibrary.exe`。脚本会先清理旧 `publish` 文件夹，不能把个人数据库和作品放进该目录。目标电脑需要 .NET 10 Desktop Runtime；保留 exe 旁的 `libvlc/win-x64/` 数据目录。

### 2.3 首次使用顺序

1. 在“系统设置 → 下载”确定缓存路径。
2. 创建媒体库，添加存放成品的目录，详见第 3 节。
3. 按实际网络填写代理，确保代理地址能被服务端访问。
4. 按来源配置账号。Anime-sharing 网盘解析需要 Debrid-Link API Key，其他直链来源不使用该中转。
5. 先导入已有文件，确认浏览正常，再选择少量作品下载。
6. 需要手机访问时，在桌面端开启外部访问。

普通设置通常在选择改变或输入框失焦时保存，没有统一的“保存设置”按钮；账号页则使用“保存并检测”。

## 3. 创建媒体库与导入本地作品

### 3.1 新建媒体库

1. 打开“系统设置”，找到“媒体库”。
2. 点击“新建媒体库”，输入名称，例如“音频”。
3. 添加文件夹。Web 端填写服务端已有的绝对路径，例如 `D:\Media\Audio`。
4. 回到“媒体库”首页，点击库卡片浏览；卡片右上角 `⚙` 打开该库设置。

![单个媒体库设置](assets/manual/libsettings.png)

一个媒体库可关联多个文件夹。名称是逻辑分组，文件夹是实际磁盘位置。“默认显示”选择“作品”或“社团”，决定下次进入先看到哪种视图。

### 3.2 准备目录结构

扫描只检查数据源目录下的**一级子文件夹**。文件夹名称需包含可识别作品号：`RJ` 加至少六位数字，或 `FB`／`EH`／`PX` 加数字。

```text
D:\Media\
├─ RJ123456\                 DLsite 作品
│  ├─ DataSource\            程序保存的封面与说明等元数据
│  └─ Audio\
├─ FB12345678\               FANBOX 投稿
├─ EH1234567\                E-Hentai 画廊
└─ PX123456789\              pixiv 作品
```

如果实际结构是 `D:\Media\社团\RJ123456`，应把相应“社团”文件夹作为数据源，或先整理层级。不要把“支持 RJ/BJ/VJ 搜索”理解成“本地扫描也能识别 BJ/VJ 目录”：当前扫描正则未包含后两种。

### 3.3 扫描与元数据

| 操作 | 行为 | 使用场景 |
| --- | --- | --- |
| 扫描全部数据源 | 顺序扫描所有有文件夹的媒体库 | 首次导入、批量新增本地文件 |
| 扫描元数据 | 扫描该库、导入新目录、清理缺失作品记录，并补全所需元数据 | 日常同步 |
| 重新扫描元数据 | 上述流程并强制重新抓取元数据 | 修复缺失或过期字段、封面 |

点击后等待状态提示完成，可离开页面后再回来查看；扫描在后台进行，后续请求排队。网络抓取失败时先检查网络，再针对该库重试。

**扫描包含缺失记录清理。** 数据源根目录可以访问、但其中某个作品文件夹已不存在时，该作品记录会被删除。整个根目录不可达（如网络盘掉线、移动盘未插）时会跳过该目录的清理，不会误删。作品文件夹只是暂时改名或搬走时，先恢复再扫描。

### 3.4 改名、换盘与移除

- **库改名**：在 `⚙ → 名称` 修改，同步更新作品所属库、下载目标和监控目标中的库名。
- **文件夹编辑**：适用于文件已经迁移或盘符变化；填写存在的新路径，程序更新相关绝对路径前缀。它不会替你搬运整个数据源目录。
- **移除文件夹**：只从媒体库配置中解除该数据源，后续扫描范围随之变化。已从该文件夹导入的作品记录不会删除，仍显示在该库中，之后的扫描也不会清理它们；确实不要的作品请在详情页逐个删除。
- **删除媒体库**：删除库配置，界面明确说明保留本地文件和已导入作品记录，与“删除作品”含义不同。这些作品的所属库会被清空，不再出现在任何库卡片里，但仍可通过首页搜索及“作品标签／作品社团／作品形式”找到。

## 4. 浏览、搜索与分类

### 4.1 库内浏览

1. 点击媒体库卡片。
2. 若进入社团分组，再选社团进入作品列表。
3. 使用顶栏“显示作品／显示社团”原地切换视图。
4. 用排序下拉选择当前列表提供的条件。
5. 点击作品卡片进入详情；左上角“返回”回到上一层。

### 4.2 搜索已有作品

首页、库内以及标签／形式分组内的范围搜索，后端实际按作品号和作品名匹配；首页覆盖所有库，库内限制当前库。进入具体作品列表后，本地卡片过滤还包含社团。界面占位提示虽含“社团”，但不能据此认为每一层都支持按社团名检索。查找社团时可使用“作品社团”入口。清空输入框恢复原视图。

左侧“作品搜索”用于外部来源检索。找已经导入的文件，优先用媒体库顶栏。

### 4.3 分类、社团与收藏

![作品形式分类](assets/manual/types.png)

“作品标签”按标签聚合；“作品社团”汇总各库社团；“作品形式”按已有元数据分组。点击分组逐级进入作品。形式名称可能保留日文，或存在相近的不同写法。

社团卡片右上角编辑入口可设置显示别名、FANBOX 主页和 pawchive 主页。别名只改变显示映射，不改作品记录中的真实社团名；卡片有主页链接时可直接打开。

“我的收藏”由作品详情页的收藏开关维护，不会复制文件。

## 5. 作品详情、收藏与文件管理

详情页结构是“标题 → 可折叠作品详情 → 作品文件”。作品文件夹存在时默认收起介绍，方便直接找文件；点击“作品详情”展开封面、作品号、社团、发售日、标签与正文。作品文件夹不存在时默认展开介绍。

可点击的标签、声优、系列等字段会打开筛选结果。作品号链接一律指向 DLsite 站点作品页，因此只对 DLsite 作品有效；FANBOX、E-Hentai、pixiv 作品点开没有对应页面。

| 顶部按钮 | 用法与影响 |
| --- | --- |
| ☆／★ 已读 | 切换阅读标记，不移动文件 |
| ♡／♥ 收藏 | 加入或移出“我的收藏” |
| 移动媒体库 | 仅在作品文件夹存在时显示；选择目标库及文件夹，确认后移动实际作品目录并更新记录 |
| 删除作品 | 删除作品目录、数据库记录、相关下载记录与缓存等，当前实现不可恢复 |

移动前确认目标盘空间和文件占用；删除前核对作品名称，不能把它当作“仅从列表隐藏”。

“已读”标记、下载历史中的“已品悦”状态，以及名为“已听”的自建库属于不同概念。源码把“已品悦”用作媒体库可见状态：本地导入和成功解压入库也会设置它，不代表用户已经听过或看过。不能只凭库名或该状态判断阅读进度。

## 6. 看图、音频与视频播放

### 6.1 文件浏览

详情下方直接显示“作品文件”，可切换“缩略图”和“文件列表”。缩略图适合图片，文件列表显示名称、大小和可折叠目录树。缩略图模式点击文件夹进入下一层；文件列表模式点击目录行展开。

### 6.2 图片

点击图片打开大图。Web 支持左右切换；触屏左滑下一张、右滑上一张，上下滑退出。`Esc`、关闭按钮、点击空白或浏览器返回也可退出大图。返回首先关闭大图，不会直接跳出作品页。同层图片组成浏览集合，子文件夹需单独进入。

### 6.3 音频

点击音频启动底部播放条。同层音频按名称顺序组成队列，可暂停、切换上一首／下一首、拖动进度、打开播放列表选曲。已播放超过约 3 秒或正在播第一首时，“上一首”会回到当前曲开头（两端相同）。

睡眠定时两端不同：

- **Web 端**：可选 15／30／45／60／90 分钟预设、自定义分钟或“播放完当前”。**到点后会让当前曲播放完，再停止续播**，不是立即截断。
- **桌面端**：只有 15／30／45／60／90 分钟预设，**到点立即暂停**并保留进度，可随时继续播放。

桌面 NAudio 播放另有响度归一化。

### 6.4 视频与其他文件

点击视频打开播放器，同层视频组成队列并支持续播。桌面由 LibVLC 解码；Web 取决于浏览器的容器和编码支持，桌面能播不代表 Edge 一定能播。

普通文件通过浏览器打开对应地址，最终预览还是下载取决于文件类型和浏览器。`.exe` 使用第 16 节流程。

## 7. DLsite 与 Anime-sharing 下载

![作品搜索入口](assets/manual/search.png)

### 7.1 查询

1. 打开“作品搜索”，来源选“DLsite”。
2. 输入 RJ/BJ/VJ 作品号、RG 社团号或 DLsite 链接，点击“查询”或按回车。
3. 单作品进入来源结果；社团／目录输入进入作品网格，可向下加载更多。

当前 Web 输入提示没有承诺任意标题全文搜索，优先使用上述编号或链接。

### 7.2 中转配置

论坛流程提取帖子中的网盘链接，经 Debrid-Link 解析后下载。在“系统设置 → Debrid-Link 下载中转站”填写自己的有效 API Key，并使用“测试”确认可用。实际支持的网盘与可用额度由中转服务返回。

### 7.3 下载方式

| 方式 | 步骤 |
| --- | --- |
| 手动选择来源 | 打开帖子结果，等待提取及检测，点击有效网盘组，选择目标库和文件夹 |
| 组合下载 | 点击帖子“组合下载”；优先 Rapidgator，用其他网盘同名分卷补齐，完整才入队，缺口会提示 |
| 单作品自动下载 | 该作品论坛扫描到帖子（显示“AS·N帖”）后，网格点击“自动下载”，选目标后交给后台检索、检测和解析；扫描到之前按钮为灰色 |
| 网格自动下载 | 打开工具栏开关，预选一次目标，随后处理符合条件的作品并继续分页，可能产生大量任务 |

卡片状态包括“待扫描”“AS·N帖”“AS·无”“不喜欢”“待下载”“下载中”“已下载”“已品悦”。帖子命中不保证分卷完整或可下载。“不喜欢”用于跳过不想处理的作品。

曾加入下载的作品可能提示已有记录，先核对历史避免重复。入队后到“下载管理”看实际进度。

## 8. asmr.one 直链下载

此流程以**桌面端**为准。asmr.one 面向语音／ASMR（SOU），不使用 Debrid-Link。

1. 桌面“系统设置 → ASMR.ONE”填写账号密码，点击“登录测试”。
2. 选择镜像站，勾选下载文件类型，例如 mp3、flac、wav、图片和字幕等。
3. 在“作品类型优先搜索”把 SOU 来源选为 asmr.one。
4. 作品搜索按 RJ 号查询 SOU 作品。
5. 使用 asmr.one 直链下载横幅的入口，选择目标库。

账号已配置且站点查无作品时会回退 Anime-sharing。账号未配时可能仍显示横幅，但下载会提示先配置，不代表资源已可用。直链保留多级目录。

当前 Web 搜索没有对应横幅或调用入口，不能照搬桌面步骤；由桌面创建的任务可在 Web 共用队列查看。

## 9. FANBOX 归档与官方来源

### 9.1 来源区别

| 下拉显示 | 来源 | 账号条件 |
| --- | --- | --- |
| FANBOX | pawchive 归档 | 不要求 FANBOX 登录 |
| FANBOX（账号名） | fanbox.cc 官方站 | 先在“账号访问”保存并检测 FANBOX 登录 |

官方来源仅能读取账号有权访问的内容。“需赞助”表示当前账号无权读取相应投稿，下载按钮禁用。

### 9.2 搜索、预览与下载

1. 选来源，输入作家名、ID 或对应来源的作家链接。
2. 查询；归档首次需下载作家索引，可能较慢。
3. 多个匹配时选择作家，单个匹配可能直接进主页。
4. 点投稿封面／标题查看正文、图集、附件及受支持的外部文件信息。
5. 单篇用卡片或详情工具栏“下载”；多篇先用卡片“选择”，再“下载选中”。
6. 选目标库和文件夹，核对入队／跳过数量，转下载管理检查。

“全选”作用于当前已加载且可选择的投稿；继续加载后核对选择数。卡片本体用于看详情，不等于选中。已下载／下载中仍能查看，不可重复选。

官方来源留空查询可列出赞助／关注作家。切换归档与官方来源会重置对应数据，不要混淆两边结果。

### 9.3 入库文件

投稿目录为 `FB<投稿ID>`，图片按顺序编号，附件通常保留原名并带序号。受支持的外部共享文件展开后入队。开启自动解压时，压缩附件会逐层解开（包里套的包也继续解），内容统一平铺进作品根目录，不保留解压时的中间目录；与已有文件重名时自动加 `_2`、`_3`，不覆盖。解压成功的压缩包会被删除；打不开的保留原样，作品照常入库。可下载性仍取决于链接及来源支持。

下载后统一在“媒体库”查看，搜索页不是独立的本地库。作家监控见第 12 节。

## 10. E-Hentai 与 pixiv

### 10.1 E-Hentai／ExHentai

1. 桌面系统设置中选择站点和画质，按需连接测试。
2. 访问需要权限的内容时，在“账号访问”配置登录信息。
3. 作品搜索选 E-Hentai，输入关键字、标签查询（如 `artist:名称`）或画廊链接。
4. 点卡片预览详情和标签；单本用“下载／下载本篇”，批量用“选择 → 下载选中”。
5. 选目标库，完成后在媒体库打开 `EH<画廊ID>`。

原图选项需要来源支持；未登录时后端可退回显示图。ExHentai 访问取决于账号权限及有效 Cookie。

### 10.2 pixiv

1. 按内容需要，在“账号访问”配置 pixiv 登录。
2. 桌面设置选择画质、搜索分级及标签匹配方式。
3. 搜索来源选 pixiv，输入关键字、标签、作品链接或作品号。
4. 点卡片看详情；用卡内“选择／下载”或“下载选中”入队。
5. 完成后在媒体库查看 `PX<作品ID>`。

未登录时站点可能过滤 R-18 结果，能选 pixiv 来源不代表账号有效。详情预览也不代表已下载原图，原图由下载流程获取。

**pixiv 收藏**：登录 pixiv 账号后，来源下拉里每个账号多一项“pixiv 收藏（账号名）”。选中后直接点“查询”即列出该账号的全部收藏（先公开收藏，后非公开收藏，下拉到底自动加载更多）；输入框里填收藏标签则只列带该标签的收藏。选择与下载方式同普通 pixiv 搜索。作者已删除或设为不公开的作品不会出现在列表里。

## 11. 下载队列、解压与已下载记录

![下载管理](assets/manual/download.png)

### 11.1 开始、暂停和进度

点击作品名称或箭头展开文件／分卷，可看进度、速度、状态、错误原因及“复制链接”。多级直链目录按原结构展示。

“开始下载”启动引擎，运行时变为“暂停下载”。“暂停中…”表示正在收尾，等待完成。单作品“下载／停止”按状态出现；断点续传取决于源站是否支持 Range。

系统设置“自动下载”是引擎相关配置，搜索网格“自动下载”是批量创建任务，监控是定时发现新投稿，三者分别理解。

### 11.2 重试与清理

| 按钮 | 用途与影响 |
| --- | --- |
| 重新解析 | 重新获取失败任务下载地址 |
| 全部重新解析 | 重排解析失败和无可用连接任务，当前实现还会启动下载引擎 |
| 重新搜索 | 仅在有失败任务时出现，确认后**删除该作品的文件夹（无论是否已入库）、下载记录和作品记录（含“已品悦”）**，再跳回搜索；不可恢复 |
| 清除已完成 | 清理完成及“源站无此文件”的终结行；正在解压的保留 |
| 清除无可用连接 | 清理失败占位任务及相应未落地占位记录 |
| 清空列表 | 清理全部队列行及相应未落地占位记录，不等于暂停 |
| 作品行“删除” | 停止并移除该任务。未入库作品连作品记录一起删除；已入库（“已品悦”）作品只移出下载列表，仍留在媒体库。只删除位于下载缓存目录下的文件夹。不同于媒体库的“删除作品” |
| 跳转作品 | 已有作品记录时打开媒体库详情 |

按钮灰显通常表示没有适用任务。临时停止用暂停，不用清空或删除代替。

### 11.3 流量与下载参数

右上角 Debrid-Link 用量卡可看各网盘额度和耗尽状态，只针对中转来源。限流、低速或失败时先展开文件看原因。

系统设置可调单文件线程数（1～6）、最低速度和全局限速（KB/s，0 为不限速）。单文件线程数不是同时下载作品数量。频繁限流时降低并发，等待来源恢复。

### 11.4 自动解压

开启后由已安装 Bandizip 或内置 SharpCompress 处理压缩包，尝试整理嵌套目录与修复部分文件名编码，再导入目标库。

加密包先尝试同目录说明文件中的密码，再试设置中的密码库。“＋”逐条添加密码，删除会确认。解压失败先查分卷、密码、空间、占用与编码，不要只反复重下。

### 11.5 已下载

工具栏“已下载”进入历史表格。可按作品号／名称／社团搜索，按下载中／已下载／已品悦筛选，点击表头排序，刷新，对“已下载”记录标记已品悦或跳转作品。“← 下载”返回队列。

## 12. 作家监控

![作家监控](assets/manual/watch.png)

目前监控 **pawchive FANBOX 归档作家**，不是官方站订阅轮询。

1. 在“作品搜索 → FANBOX”进入作家主页。
2. 点击“+ 监控作家”，选择目标媒体库和文件夹。添加后按钮变为“✓ 已监控”。
3. 按提示选择“全部下载”或“只要新作品”：前者把已有投稿也入队，后者从现在起关注新投稿。
4. 打开“作家监控”，核对目标、间隔和下次检查时间。

全局开关控制自动轮询，关闭后“立即检查”仍可用。默认间隔与单作家间隔可分别调整；卡片支持立即检查、暂停／恢复、打开主页、删除监控，并显示上次结果及累计数量。

删除监控不删除已下载作品。程序必须运行、目标目录可访问；发现新投稿与实际完成下载是两个阶段，以队列为准。

## 13. 账号访问

本页管理 FANBOX、pixiv、E-Hentai 的登录账号，不管理 Web 访问密码和 asmr.one 账号。

账号只能**在服务器上登录**：点击卡片下方的“🖥 在服务器上登录”，运行本程序的电脑上会打开一个登录窗口，打开对应站点的登录页。桌面端直接在窗口里登录；Web 端会把这个窗口的画面串流到网页上操作（点画面即点击，手机上用“Aa 输入文字”输入账号密码）。登录成功后程序自动取得登录信息、保存为账号并关闭窗口。

| 站点 | 账号数 | 说明 |
| --- | --- | --- |
| FANBOX | 可登录多个 | 作品搜索的来源下拉中，每个账号各有一项“FANBOX（账号名）”。从哪个账号加入下载，就用哪个账号下载（不同账号赞助的作家不同时有用）。 |
| pixiv | 可登录多个 | 每个账号各有一项“pixiv（账号名）”；一个账号都没有时是匿名的“pixiv”（结果中不含 R-18）。 |
| E-Hentai | 一个 | 在论坛登录页登录。程序会自动领取里站 exhentai 的访问权限；账号没有里站权限时只能用表站。再次登录即替换原账号。 |

每个账号一行，显示账号名与用户号：“检测”检查登录是否有效，“退出登录”删除该账号，同时删除服务器上它的浏览器登录记录。想再添加一个 FANBOX／pixiv 账号，点击“＋ 在服务器上登录其它账号”，在新窗口里登录另一个账号即可；同一账号重新登录会更新原来那一行。

**自动维护**：程序启动 1 分钟后及之后每 6 小时，会逐个检测已登录的账号。登录信息失效时，程序会用该账号登录时留下的浏览器登录记录自动续上；账号行下方显示最近一次维护的时间和结果。只有当浏览器里的登录也过期（需要重新通过人机验证）时，才需要再“在服务器上登录”一次。旧版本手动填写过的 Cookie 会自动转成账号，但它们没有浏览器登录记录，失效后需要重新登录。

数据库包含保存的账号登录信息，不应把数据库、`cache/webview2` 文件夹放入公开截图或仓库。

## 14. 系统设置与封面图床

### 14.1 设置项

| 分区 | 内容 |
| --- | --- |
| 下载 | 缓存、自动下载／解压、线程、最低速度、限速、密码库 |
| 代理 | 开关、类型、主机、端口，用于程序访问外部来源 |

语言提供简体、繁体、日文、英文。排查时可临时提高日志级别，日志在 `log/`。解压编码默认 `cp437`，有实际乱码问题时再调整。

Web Debrid-Link 的眼睛按钮要求访问密码后才显示已存明文，平时无需展开。API Key 和图床 Token 留空通常表示不修改，不等于清空。

### 14.2 图床

1. 准备项目支持的自建图床、项目标识和 Token。
2. 填地址、项目和 Token，点击“测试连接”。
3. 成功后启用，已有封面按需点击“迁移封面”。
4. 等状态完成，回媒体库确认封面显示。

图床提供封面与缩略图，减少机械盘随机读取，不会把音视频和附件全部搬过去。失败时先检查连接及配置，保留本地数据。

## 15. Web 访问与门户登录

### 15.1 局域网

1. 桌面“系统设置 → 外部访问”设端口、密码并开启。
2. 按状态提示检查监听情况。
3. 同网络浏览器打开 `http://<主机局域网地址>:<端口>/`，默认 8080，以实际设置为准。
4. 如出现登录页，使用本项目配置的访问密码。

不通时先在主机用 localhost 验证服务，再查主机 IP、端口、网络与防火墙。另一设备的 localhost 不是服务端。

### 15.2 门户与 SSO

本次界面通过既有门户代理访问。门户域名、客户端标识和代理子路径属于部署信息，不是项目默认值。

桌面“门户单点登录”提供启用、Client ID、门户地址、内网地址、Client Secret 和用户列表配置。部署者应使用门户分配参数并核对回调，配置完成后使用“门户登录”，不能仅填门户 URL 就认为已完成。

当前 Web 部分请求使用根路径 `/api/...`，串流 WebSocket 也如此。**子路径代理需要网关配套转发**，首页能开不代表所有 API 和串流都通。本次未执行 SSO 重配或串流连通性测试。

## 16. 游戏运行与远程串流

1. 在作品文件找到 `.exe`，Web 点击后选“本机运行”或“远程串流”。
2. 本机运行指**服务端 Windows 电脑**，即使浏览器在另一 Windows 电脑上也是如此；非 Windows 浏览设备上该选项显示为灰色、不可选。
3. 串流把服务端程序画面传回网页，将键鼠／触摸输入回传主机。

触屏提供方向键、Z、X、Enter、Esc、Shift、Ctrl、空格、Tab 等，可切换声音和全屏。只保留一路串流，新连接接管旧连接。

关闭串流页或断网**不会结束程序**，可重连继续。需要关闭游戏时点“结束程序”。主机需有可操作 Windows 桌面和正常程序窗口。

一直等待窗口先查主机程序是否启动；连接失败再查 WebSocket 和代理转发，尤其是门户子路径场景。

## 17. 图片翻译的当前实现范围

桌面已提供模型档位、CPU／GPU、模型目录、嵌字字体、依赖下载／取消／删除等设置。依赖不齐时不能启用；切到未下载档位或目录会停用。约定的译图路径是作品目录下 `translated/`，不覆盖原图。

**当前尚未接入实际图片翻译执行与查看入口。** `TranslateService` 负责就绪判断和路径约定；全文核对没有发现看图或详情页触发 OCR、翻译、嵌字的流程，Web API 也没有对应执行路由。

因此只能按“依赖管理已存在”理解，不能按“下载模型、开启后就自动生成译图”使用。日常媒体库功能无需下载这些模型。

## 18. 备份、迁移与问题排查

### 18.1 备份迁移

正常关闭程序并确认任务停止后，备份实际使用的 `R-18MediaLibrary.db`、全部媒体库数据源（包括 `DataSource` 元数据）、回退 `images/` 目录；按需保留缓存、模型和日志。

SQLite 使用 WAL，运行中只复制 `.db` 可能漏掉未归并数据。优先退出后复制；在线备份需使用 SQLite 一致性备份方式。数据库含账号信息，按私有文件保管。

数据库优先查工作目录，再从 exe 目录向上查，都没有才在 exe 目录新建，迁移前核对用的是哪份。旧 `DLsiteMedia.db`／`DASD.db` 在没有新名库时尝试迁移，先备份。

换盘先恢复文件，再用媒体库“文件夹 → 编辑”更新路径，确认文件可打开后再扫描，不要先扫描不可用旧目录。

### 18.2 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 缺少 .NET | 发布版需要 Desktop Runtime 10，源码需要 SDK 10 |
| 导入零作品 | 服务端路径、一级子目录、名称中的 RJ/FB/EH/PX 编号 |
| 换盘后打不开 | 编辑数据源路径，检查运行账号读取权限 |
| 元数据／封面不全 | 来源网络、代理、扫描状态，必要时重新扫描该库 |
| 找不到本地作品 | 当前搜索范围，回首页搜并清空过滤 |
| 无 FANBOX 官方选项 | 账号访问中保存并检测登录后重进搜索 |
| pixiv 结果缺失 | 账号有效性、分级、匹配与作品访问权限 |
| 网盘解析失败 | Key、网盘支持、额度、链接失效情况 |
| 无可用连接 | 可能仅有帖子，检查错误与分卷，再重新解析 |
| 任务不动 | 引擎、单作品停止状态、解析／冷却、磁盘空间 |
| 100% 仍不能浏览 | 是否等待解压、解压失败或尚未完成入库 |
| 解压失败 | 密码、说明文件、分卷、空间、占用和编码 |
| 桌面能播网页不行 | 浏览器编解码支持，使用桌面播放器或兼容格式 |
| 监控不更新 | 主进程、总开关、暂停、间隔、来源网络、目标盘和队列 |
| 手机打不开 | 主机程序、外部访问、IP、端口、网络及防火墙 |
| 门户部分操作失败 | 根路径 API 和 WebSocket 是否配套转发 |
| 模型已下无翻译按钮 | 当前只有依赖管理，翻译执行尚未接入 |
