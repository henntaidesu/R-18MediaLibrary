# R-18MediaLibrary · R18 メディアライブラリ

[简体中文](../README.md) · **日本語** · [English](README.en.md)

**画像付きシステム紹介：** [简体中文](系统展示.md) · [日本語](系统展示.ja.md) · [English](系统展示.en.md)

Windows 向けのローカルメディアライブラリ兼ダウンロード管理ツールです（WPF・C#・.NET 10）。作品の取り込み、メタデータ補完、多軸分類、音声・動画再生、ブラウザからのリモートアクセスに対応しています。

**[操作マニュアル](使用手册.ja.md)**

![メディアライブラリ Web トップ](assets/manual/home.png)

## 機能

| 機能 | 現在の実装 |
| --- | --- |
| メディアライブラリ | 複数ライブラリ・複数データソース；作品／サークル表示の切り替え；スキャン取り込み、メタデータと表紙の補完；ライブラリ名変更とパス更新 |
| 閲覧と整理 | ローカル検索、並べ替え、タグ、サークル、作品形式、お気に入り、既読、作品の移動と削除 |
| 再生と画像閲覧 | ファイルツリー／サムネイル、大画像のページ送り、音声・動画キュー、スリープタイマー；デスクトップは LibVLC 動画と NAudio 音声 |
| DLsite ソース | 作品番号／サークル／カタログ検索、Anime-sharing スレッド解析、ファイルホスト確認、分割アーカイブの組み合わせダウンロード |
| asmr.one | デスクトップで SOU 作品を直リンク取得、ファイル種別フィルター；該当作品がなければフォーラムソースへフォールバック |
| FANBOX | pawchive アーカイブで作家を検索；ログイン後は公式ソースを追加；単一・一括ダウンロード |
| E-Hentai／pixiv | 検索、詳細プレビュー、単一／一括ダウンロード、完了後はライブラリへ統一的に取り込み |
| ダウンロード管理 | 進捗、レジューム、一時停止、解析リトライ、速度制限、使用量、自動展開と履歴 |
| 作家の更新確認 | pawchive の作家の新規投稿を定期確認、作家ごとの間隔・一時停止・即時確認に対応 |
| アカウント | FANBOX、pixiv、E-Hentai のログイン情報の設定・確認・削除 |
| Web と配信 | HTTP サーバー、アクセスパスワード、任意のポータル SSO；ゲームはサーバー側の Windows で動かし Web へ配信 |
| 表紙用画像ホスト | 任意の自前画像ホスト、接続確認、既存表紙の移行 |

画像翻訳はデスクトップの設定とモデル依存関係の管理まではありますが、**実際の翻訳実行と表示の入口は未接続**のため、完成機能には含めていません。詳細は[マニュアル第 17 節](使用手册.ja.md#17-画像翻訳の実装範囲)を参照してください。

## クイックスタート

### ソースから実行

Windows と .NET 10 SDK が必要です。リポジトリのルートで実行します：

```powershell
dotnet build src/R-18MediaLibrary.csproj
dotnet run --project src/R-18MediaLibrary.csproj
```

`start.bat` をダブルクリックすると Release 構成で実行できます。

### 発行

`publish.bat` を実行すると `publish/R-18MediaLibrary.exe` が生成されます。実行先の PC には **.NET 10 Desktop Runtime** が必要で、exe の横にある `libvlc/win-x64/` データフォルダーも残してください。

スクリプトは古い `publish` フォルダーを削除します。個人ファイル、データベース、メディアライブラリを中に置かないでください。

### 初回の使い方

1. システム設定でダウンロードキャッシュのパスとネットワーク設定を確認します。
2. メディアライブラリを作成し、プログラムを実行している PC 上のデータソースフォルダーを追加します。
3. 既存の作品を取り込み、スキャンとメタデータ補完を待ちます。
4. ソースに応じてアカウントまたは Debrid-Link を設定し、作品検索で検索して取り込み先ライブラリを選んでダウンロードします。
5. ダウンロード管理で進捗を確認し、完了後はメディアライブラリで閲覧・再生します。

ローカルスキャンはデータソース直下の一階層目のサブフォルダーを対象とし、名前に `RJ` と 6 桁以上の数字、または `FB`／`EH`／`PX` と数字を含む必要があります。検索で使える番号とローカルスキャンの対象は完全には一致しません。

## ソースと前提条件

| ソース | 前提条件 | ダウンロード方式 |
| --- | --- | --- |
| Anime-sharing | 有効な Debrid-Link Key、利用可能なファイルホストの容量とリンク | フォーラムのファイルホスト → 中継解析 → キャッシュ／展開 → メディアライブラリ |
| asmr.one | デスクトップでアカウント、SOU 優先ソース、ファイル種別を設定 | 直リンク、多階層フォルダーを保持 |
| FANBOX アーカイブ | pawchive ソースにアクセスできること | 投稿と対応添付の直リンク、フォルダー `FB<投稿ID>` |
| FANBOX 公式 | 有効なログインと、該当コンテンツの閲覧権限 | 公式投稿、フォルダーは同上 |
| E-Hentai／ExHentai | サイトとコンテンツの要件に応じてログインを設定 | ギャラリー画像、フォルダー `EH<ギャラリーID>` |
| pixiv | コンテンツに応じてログインを設定。未ログインでは R-18 結果が除外される場合あり | 作品画像、フォルダー `PX<作品ID>` |

Debrid-Link は対応ファイルホストの解析のみを担い、ソース側のアカウント権限の代わりにはなりません。FANBOX の作家の更新確認は現在アーカイブソースのみを使います。

## デスクトップ版と Web 版

デスクトップの「システム設定 → 外部アクセス」で有効化、ポート、パスワードを設定し、ブラウザで `http://<ホストアドレス>:<ポート>/` を開きます（既定ポート 8080）。Web とデスクトップはデータベース、ファイル、タスク、更新確認を共有します。

Web 上のフォルダー、ダウンロード先、「このPCで実行」はすべて**サーバー側の PC** を指します。プログラムを終了すると Web、ダウンロード、更新確認は停止します。Web での再生互換性はブラウザ次第で、デスクトップはローカルの再生エンジンを使います。

asmr.one の直リンク入口、SOU 優先ソース、E-Hentai の画質／サイト、pixiv のレーティング／一致方式／画質、外部アクセスと SSO のパラメーターはデスクトップで設定します。現在の Web 検索には asmr.one 専用の入口はありません。

ポータル経由のプロキシには API と WebSocket の転送設定が必要です。現在一部のリクエストはルートパス `/api/...` を使うため、サブパスでトップページが開けてもすべての機能が使えるとは限りません。デプロイと配信の制限は[操作マニュアル](使用手册.ja.md)を参照してください。

## 設定とデータ

設定は SQLite `R-18MediaLibrary.db` の `conf` テーブルに保存され、[AppConfig.cs](../src/Core/AppConfig.cs) が管理します。通常の設定はフォーカスが外れたときや選択時に保存され、アカウントページは「保存して確認」を使います。

| データ | 場所／役割 |
| --- | --- |
| データベース | 作業ディレクトリを優先し、次に exe のフォルダーから上位へ探索；見つからなければ exe のフォルダーに作成 |
| メディアライブラリ | ユーザーが設定したデータソースフォルダー。作品と `DataSource` メタデータなどを保存 |
| ダウンロードキャッシュ | システム設定のキャッシュパス |
| フォールバック表紙 | 作業ディレクトリの `images/` |
| ログ | 作業ディレクトリの `log/` |
| ソースキャッシュ | `cache/`（pawchive の作家インデックスなど） |

旧 `DLsiteMedia.db` または `DASD.db` は、新しい名前のデータベースがない場合に移行を試みます。バックアップの前にプログラムを正常終了し、実際のデータベースの場所を確認してください。データベースにはアカウント情報が含まれるため、公開リポジトリにコミットしないでください。

「メディアライブラリの削除」はファイルと取り込み済みの記録を残します。「作品の削除」は実フォルダーと関連記録を削除し、元に戻せません。スキャンは存在しない作品の記録も削除するため、ネットワークドライブやリムーバブルドライブが使えない場合は先にマウントを復旧してください。

## 開発ガイド

```text
src/
├─ Core/                 SQLite、設定、ログ、ネットワーク、言語
├─ Views/                WPF ページとダイアログ
├─ Controls/             ファイル・再生などの UI コンポーネント
├─ Services/             ソース、ダウンロード、展開、メディアライブラリ、Web、配信
│  └─ Translate/         翻訳モデルの依存関係管理などの基盤コード
└─ Web/                  組み込み Web フロントエンド
docs/
├─ 使用手册.md           機能別の手順、制限、トラブル対処（.ja / .en あり）
├─ 系统展示.md           画像付きの機能紹介（.ja / .en あり）
├─ README.ja.md / README.en.md
└─ assets/manual/        Edge で撮影した実画面
```

主な依存関係は Microsoft.Data.Sqlite、HtmlAgilityPack、SharpCompress、LibVLCSharp、VideoLAN.LibVLC.Windows、NAudio、CommunityToolkit.Mvvm で、バージョンは[プロジェクトファイル](../src/R-18MediaLibrary.csproj)を基準とします。アセンブリ名は `R-18MediaLibrary`、C# のルート名前空間は `R18MediaLibrary` です。

マニュアルは 2026-10-26 時点のソースと Web 画面で確認し、機能とソースの対応表を付けています。ダウンロード、削除、移動、ログイン、配信はドキュメント作成時に実際には実行していません。

自分がアクセス権を持つコンテンツのみを管理し、各ソースの利用規約を守ってください。
